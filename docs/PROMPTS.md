# Prompt-engineering log

This log records the actual prompting approach for this project. It is factual: it does
not invent prompts, message ids, or events.

## Runtime prompting (agent play): none for moves
Per the project brief, **the MOVE is always pure Python** — no LLM is invoked to choose
an action. The agent's default hint provider is offline `template` (0 tokens): hints are
generated by `strategy/hints.py` from a small fixed set (truthful / vague / deceptive
templates) and pass the public-safety filter. Therefore there is no runtime prompt to
tune for gameplay, and no token budget is consumed by moves or default hints. An
optional LLM hint provider (`ollama` / `claude_api` / `claude_cli`) is described by the
config schema but is not enabled; if enabled later, hints would still pass the same
≤15-word, no-leak filter, and moves would remain pure Python.

## Development prompting (how the code was built)
The implementation was produced through a sequence of task-scoped engineering prompts,
one per delivery phase. The phases actually executed (see Git history and `docs/TODO.md`):
- Day-1: local-playable core (board/rules/capture/scoring/scent/crypto, strategy base,
  firewall+fallback, artifacts+audit, headless simulator).
- Day-2 Part 1: real FastMCP transport, reliability, idempotency, networked series.
- Day-2 Part 2 (P12–P17): opponents + evaluation harness, advanced Police/Thief
  portfolios, audit-gated profiling, adaptive meta-controller, free-language hints.
- Day-2 Part 2 production integration: shared production brain factory wired into
  local + network + responder; profiling across the series; network barriers.
- Day-2 Part 3 (P20/P21): replay viewer + local-truth GUI.
- Day-3 (P22–P28): two-peer confirmation, Gmail reporting, tunnel adapter, bounded
  tuning, red-team, local counted rehearsal, documentation, pre-submission audit.

Each development prompt required: smallest safe changes, ≤150 physical lines per file,
≥85% branch coverage, ruff clean, no secrets, symmetric changes to both repos, and an
independent review pass. The exact prompt texts live in the chat history that produced
this repository; they are not reproduced verbatim here to avoid fabrication.
